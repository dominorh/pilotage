Première utilisation (une seule fois par poste)

  1. Synchroniser le dossier SharePoint

    Sur le site SharePoint de l'agence, ouvre la bibliothèque Documents, puis clique sur Synchroniser (ou Ajouter un raccourci à Mon OneDrive). Le dossier apparaît dans l'explorateur Windows, sous OneDrive.

    Documents └─ Pilotage ├─ Planning ← le planning Excel ├─ Marges ← les exports CSV de marges └─ Actions ← les exports Excel des actions

  2. Garder les fichiers sur le poste

    Dans l'explorateur, clic droit sur le dossier Pilotage → Toujours conserver sur cet appareil. Les mises à jour des collègues arrivent ainsi plus vite.

  3. Ouvrir l'outil avec Edge ou Chrome

    Clique sur l'outil voulu ci-dessus, puis sur « Choisir le dossier » et sélectionne le sous-dossier correspondant (par ex. Pilotage › Planning). Accepte l'autorisation demandée par le navigateur.

  4. C'est tout

    Le dossier est mémorisé. Les jours suivants, ouvre simplement l'outil (un clic sur « Reprendre la surveillance » peut être demandé). Dès qu'un fichier est ajouté ou modifié dans le dossier, la page se met à jour.

Questions fréquentes

Mes données partent-elles sur internet ?

Non. Les fichiers Excel et CSV sont lus par ton navigateur, sur ton poste, et ne sont jamais envoyés. La page se connecte uniquement à la base de l'agence, pour vérifier ton compte (et, pour le planning partagé, lire et enregistrer le planning).

Les chiffres ne sont pas à jour
  • Regarde la ligne « Version la plus récente reçue » sous l'état de la surveillance : si l'heure est ancienne, c'est OneDrive qui n'a pas encore synchronisé.
  • Vérifie que l'icône OneDrive (barre des tâches) n'est pas en pause, puis clique sur ↻ Relire maintenant.
  • Dans Excel, active l'enregistrement automatique.
« Fichier illisible » ou « fichier ouvert dans Excel »

Le fichier est verrouillé par Excel sur ce poste. Ferme-le (ou attends la fin de l'enregistrement) : la page le relit toute seule.

Le bouton « Choisir le dossier » ne fait rien

Utilise Edge ou Chrome. Firefox et Safari ne savent pas surveiller un dossier : ils peuvent seulement lire des fichiers ajoutés à la main.

Modifier le planning en même temps qu'un collègue ?

Évite de modifier le même planning au même moment, l'un dans Excel et l'autre dans la page : OneDrive créerait une copie en conflit. Avant chaque modification, la page vérifie que la ligne n'a pas bougé ; une copie de sauvegarde est faite dans _sauvegardes.

J'ai supprimé un fichier par erreur

Il n'est pas perdu : il a été déplacé dans le sous-dossier _corbeille du dossier surveillé. Remets-le à sa place.

Pour ajouter ces outils sur une page SharePoint

À faire une fois, par une personne qui peut modifier une page du site SharePoint (pas besoin d'être administrateur).

  1. Sur la page SharePoint du site : Modifier (en haut à droite).
  2. Clique sur + à l'endroit voulu → composant Liens rapides (ou Bouton).
  3. Ajouter des liens → colle l'adresse copiée ci-dessus, donne un titre (« Outils de pilotage »). Dans les options du lien, garde « Ouvrir dans un nouvel onglet ».
  4. Republier la page.

Chaque personne se connecte ensuite sur la page d'accueil avec son compte. Ne pas utiliser le composant « Incorporer » : à l'intérieur d'une page SharePoint, le navigateur bloque le choix du dossier, les outils ne pourraient pas lire les fichiers.
